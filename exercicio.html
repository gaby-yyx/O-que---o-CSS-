Texto 1

O que é CSS?

CSS é chamado de linguagem Cascading Style Sheet
e é usado para estilizar elementos escritos em uma linguagem de marcação como HTML

Texto 2

Onde o CSS é utilizado?

é utilizada por desenvolvedores para dar dinâmica e efeitos a páginas de sites e aplicativos
construídas sobre uma linguagem de marcação, como o HTML.
